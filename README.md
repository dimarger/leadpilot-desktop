# LeadPilot Desktop

Отдельная Windows-версия LeadPilot AI. Она запускается собственным приложением, хранит настройки локально и не зависит от Sites для интерфейса.

## Web demo

GitHub Pages публикует демонстрацию интерфейса с локальным browser storage. Telegram-сессии, системный автозапуск, защищённое хранение OpenAI-ключа и остальные Electron-возможности работают только в desktop-сборке.

## Что уже перенесено

- текущий интерфейс LeadPilot;
- подключение двух Telegram-аккаунтов по номеру или QR;
- чаты, архивы, папки и автопоиск;
- локальная модель анализа лидов и вакансий;
- локальная история, агенты, профиль кандидата и события;
- SQLite-база в системной папке приложения;
- шифрование OpenAI API-ключа средствами Windows;
- системный трей и защита от запуска двух копий;
- автозапуск и конфигурация установщика Windows.

## Первый запуск на Windows

1. Установите **Node.js LTS** и **Git**.
2. Откройте PowerShell в папке проекта.
3. Разрешите запуск локального скрипта только для текущего окна:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   ```

4. Выполните:

   ```powershell
   .\scripts\setup-windows.ps1
   npm run dev
   ```

## Сборка установщика

```powershell
.\scripts\build-windows.ps1
```

Готовый файл появится в папке `release` под именем `LeadPilot-Setup-0.1.0.exe`.

## Безопасность

Telegram-сессии и рабочие настройки остаются на компьютере. OpenAI-ключ шифруется через системное защищённое хранилище Windows. Для коммерческого выпуска лицензии и платёжную проверку нужно вынести на отдельный сервер: локальную проверку подписки можно подменить.
